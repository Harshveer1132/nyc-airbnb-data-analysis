# NYC Airbnb Data Analysis

## 📌 Project Overview

An end-to-end **NYC Airbnb data analysis project** using **Excel and Power BI**.

The raw Airbnb dataset was cleaned and prepared in Excel and then analyzed in Power BI to identify patterns in **listings, hosts, neighbourhoods, room types, prices, reviews, and availability**.

## 🛠️ Tools Used

* **Excel** – Data cleaning and preparation
* **Power BI** – Data analysis, visualization, and dashboard
* **Power Query & DAX** – Data transformation and calculations

## 📊 Key Analysis

* Property distribution by neighbourhood group
* Host-wise property listings
* Average prices by neighbourhood
* Room-type analysis and availability
* Review and review-per-month analysis
* Most-reviewed properties
* Interactive filtering using Power BI slicers

## 💡 Key Insights

* **Highest number of listings:** Manhattan
* **Host with the highest number of listings:** Sonder (NYC)
* **Most preferred room type:** Entire home/apt.
* **Highest average price neighbourhood group:** Brooklyn
* **Most-reviewed property:** Room near JFK Queen Bed
